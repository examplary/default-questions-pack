The select words question type (QTI *hottext*) shows a text in which students select the right words or phrases, like the verbs in a sentence or the word that signals a cause.

## When to use it

- Grammar: select the verbs, the subject, or the word that is spelled wrong.
- Reading: select the phrase that supports a claim.
- Vocabulary: select the synonym of a given word.

## How it works for students

Students click a word or phrase to select it, and click it again to deselect it. Each selectable part is shown in a box, unless the question hides them so students have to find them themselves.

## Grading

Scored automatically: the answer is correct when exactly the right parts are selected.

## Settings

| Setting | Description |
| --- | --- |
| Text | The text, with each part students can select in `[square brackets]`. Brackets inside math are left alone. |
| Correct answer | The parts that should be selected, picked by clicking them. They are stored as their text, so a part that appears twice counts as one. |
| Show selectable words | On by default. Turn it off to show the text without any hint of which parts can be selected (QTI `qti-unselected-hidden`). |
