# Question types

The default question types of **[Examplary](https://examplary.ai)**, as an app that's
preinstalled in every workspace. Each folder is one question type: its `definition.ts`,
added in `app.ts`, with its components, README and preview images. You can use them as a basis
for your own.

`yarn test` runs their tests. `metadata.preview` in each definition holds example question and
answer data per language, for rendering previews.

Read more in the [📘 Developer Documentation](https://examplary.ai/developers/apps).
