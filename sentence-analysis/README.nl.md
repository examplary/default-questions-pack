Het vraagtype zin ontleden is gemaakt voor redekundig ontleden in de Nederlandse les: leerlingen verdelen een zin in zinsdelen, geven elk zinsdeel het juiste label en markeren eventueel de persoonsvorm.

## Wanneer gebruik je het

- Redekundig ontleden oefenen en toetsen in de les Nederlands.
- Gerichte oefeningen met specifieke zinsdelen, door alleen bepaalde labels beschikbaar te maken.
- Zowel formatief oefenen als toetsen voor een cijfer: het type wordt automatisch nagekeken.

Kies bij voorkeur enkelvoudige zinnen met een duidelijke opbouw; zo blijft de opdracht eenduidig.

## Zo werkt het voor leerlingen

De zin wordt woord voor woord getoond. Leerlingen selecteren aaneengesloten groepjes woorden om zinsdelen te vormen, kiezen voor elk zinsdeel een label uit de beschikbare set (bijv. OW, WG, LV, BWB) en markeren, als dat gevraagd wordt, de persoonsvorm. Elk woord moet in precies één zinsdeel terechtkomen. Reken op ongeveer 4 minuten per zin.

## Nakijken

Wordt automatisch nagekeken aan de hand van de ingestelde juiste verdeling, labels en persoonsvorm. AI-nakijken staat ook aan, om genuanceerde gevallen te beoordelen.

## Instellingen

| Instelling            | Beschrijving                                                                   |
| --------------------- | ------------------------------------------------------------------------------ |
| Zin                   | De zin die ontleed moet worden.                                                |
| Beschikbare zinsdelen | Welke labels leerlingen kunnen gebruiken (bijv. OW, WG, LV, BWB).              |
| Persoonsvorm markeren | Of leerlingen ook de persoonsvorm moeten markeren (staat standaard aan).       |
| Modelantwoord         | De juiste verdeling van de zin in benoemde zinsdelen, inclusief de persoonsvorm. |
